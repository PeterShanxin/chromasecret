# Chromasecret

**藏在色彩里的秘密。一个本地运行的个性化视觉感知实验室。**

[打开在线实验](https://chromasecret.vercel.app/) | [English](README.md)

我们尝试根据你在当前屏幕上的实际回答，搜索对你更容易辨认、对典型色觉观察者更难看清的图案。它不是临床色觉诊断，也不保证“只有色弱的人能看见”，更不是安全的加密工具。当前实现尚无真实参与者证据证明其选择性可读效果。

## 使用流程

1. 设置屏幕与观察环境，完成感知校准。
2. 进行探索性色觉评估，保留实际回答和不确定性。
3. 通过陌生字符和空白对照进行个性化优化。
4. 先生成单字或短词，再尝试 `hey meow` 或中文。
5. 让不知道答案的另一位观察者，在同一屏幕上完成配对验证。

页面右上角支持中文 / EN 切换，首次跟随浏览器语言，选择保存在本地。切换界面语言不会翻译你输入的秘密消息。

## 数据与科学边界

无需账号。色彩运算、优化和图像生成在浏览器内完成，没有应用后端、统计分析或远程翻译服务。托管服务仍需响应普通网页访问请求。

测试回答与档案保存在当前浏览器中；你输入的消息只放在内存，不写入档案。PNG 导出不添加明文元数据，但图像像素仍编码了消息。拥有图像处理知识的观察者可能通过颜色滤镜恢复文字，所以不要用它保护敏感信息。

这是感知校准，不是色度计测量；色觉类型和严重程度只是近似模型拟合，不是医学诊断。模拟器和自动化测试不能替代真人实验。

## 本地运行与开发

已提交的 `index.html` 可直接离线打开。需要稳定本地存储来源时，安装 Node.js 20+，运行 `npm start`，访问 `http://127.0.0.1:5173`。

修改源码后：

```sh
npm ci
npm run build
npm test
```

完整科学说明见 [FEASIBILITY](docs/FEASIBILITY.md)，实验记录见 [EXPERIMENTS](docs/EXPERIMENTS.md)。原型使用较旧的 React 运行时，尚未完成正式产品级依赖和安全审计。
